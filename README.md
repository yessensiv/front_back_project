## 📌 О проекте

Проект состоит из двух независимых страниц:

1. **Портфолио команды** — главная страница с профилями участников и четырьмя интерактивными заданиями по JavaScript и DOM.
2. **To-Do приложение** — список задач с CRUD-операциями, фильтрами и переключением темы.

Интерфейсы адаптированы для разных размеров экрана. Для запуска не нужны сборщик, сервер или установка пакетов.

## 🚀 Возможности

### Портфолио и практика DOM

- Карточки команды и подробные профили с навыками, опытом и контактами.
- Навигация между профилями и заданиями без перезагрузки страницы.
- Изменение текста и стилей, добавление и удаление элементов.
- Добавление и удаление CSS-класса с отображением текущего списка классов.
- Создание таблицы размером до 20 × 20 и интерактивная раскраска ячеек.
- Переключение светлой и тёмной темы.

### Список задач

- Загрузка задач из [DummyJSON](https://dummyjson.com/docs/todos).
- Создание, редактирование, завершение и удаление задач.
- Фильтры: все, незаконченные и законченные.
- Сохранение пользовательских изменений и выбранной темы в `localStorage`.
- Удобное управление редактированием с клавиатуры: `Enter` — сохранить, `Escape` — отменить.

> **Важно:** DummyJSON имитирует изменения и не сохраняет их на сервере. Изменения и созданные задачи сохраняются в браузере; для работы с API требуется подключение к интернету.

## 🖥️ Запуск

### Открыть локально

1. Скачайте или клонируйте репозиторий.
2. Откройте `index.html` в браузере, чтобы посмотреть портфолио и задания.
3. Откройте `todo/index.html`, чтобы запустить список задач.

Для запросов к DummyJSON нужна сеть. Остальная часть портфолио работает без подключения к интернету; внешний шрифт может не загрузиться офлайн.

### Через GitHub Pages

В настройках репозитория откройте **Settings → Pages**, выберите публикацию из ветки и корневую папку (`/root`). После публикации портфолио будет доступно по адресу GitHub Pages, а список задач — по адресу сайта с путём `/todo/`.

## 🧰 Технологии

- **HTML5** — семантическая разметка страниц.
- **CSS3** — адаптивные интерфейсы, карточки, таблицы и светлая/тёмная темы.
- **Vanilla JavaScript** — навигация, работа с DOM и логика приложений.
- **DummyJSON** — демонстрационный API для задач.
- **Local Storage** — сохранение изменений To-Do и настройки темы в браузере.

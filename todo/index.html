    Запуск: откройте этот файл index.html в браузере. Python, бэкенд и установка пакетов не нужны; для DummyJSON нужен интернет.

    HTML-теги

    • <form> и <input type="text"> — ввод и отправка новой задачи.
    • <label> — подпись поля; атрибут for связывает её с id поля.
    • <button type="submit"> — добавление; type="button" — изменение, отмена и удаление.
    • <ul> и <li> — список и отдельная задача.
    • <input type="checkbox"> — отметка «Сделано».
    • <template> — невидимый образец строки, который копирует JavaScript.
    • <dialog> — модальное окно; showModal() открывает его, close() закрывает.
    • <select> — выбор исполнителя и направления сортировки.
    • <p role="status"> — сообщение о загрузке, результате или ошибке.

    JavaScript

    API.js отправляет запросы к DummyJSON; script.js управляет интерфейсом и локальным сохранением изменений.

    /users?limit=0 загружает пользователей. Поле userId задачи связывается с id пользователя. Сортировка запрашивается через /todos?limit=0&sortBy=todo&order=asc (или desc), поиск по названию фильтрует загруженные задачи.

    • fetch() отправляет GET, POST, PATCH и DELETE; async/await ждёт ответ.
    • response.ok проверяет HTTP-ответ; try/catch/finally обрабатывает ошибку и возвращает кнопки в рабочее состояние.
    • addEventListener() обрабатывает отправку формы, клики, галочку и клавиши Enter/Escape.
    • cloneNode(true) копирует шаблон; replaceChildren() обновляет список.
    • textContent безопасно выводит текст задачи как текст, без выполнения HTML.
    • dataset и closest() помогают определить действие и нужную строку.
    • localStorage и JSON.stringify()/parse() сохраняют изменения между открытиями страницы.

    DummyJSON не сохраняет POST, PATCH и DELETE на сервере. Задачи, созданные здесь, затем изменяются и удаляются локально; для исходных задач PATCH и DELETE отправляются в API.

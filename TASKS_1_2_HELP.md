# Справка об изменениях: задания 1–2

Для выполнения заданий изменены три файла: `index.html`, `script.js` и `styles.css`.

## Навигация и разметка — index.html

Ранее кнопки заданий 1 и 2 вызывали `switchTab(2)` и открывали профиль третьего участника. Теперь они вызывают `switchTab('task1')` и `switchTab('task2')` и открывают отдельные разделы.

Добавлена строка навигации «ПРАКТИКА DOM» с кнопками заданий. Созданы разделы `view-task1` и `view-task2`, заголовки, пояснения и элементы для демонстрации результатов.

## Задание 1 — работа с DOM

Логика находится в конце `script.js`.

1. Элемент с ID `greeting` найден через `document.getElementById()`. Его текст заменён на «Сәлем, әлем!» через свойство `textContent`.
2. Через `document.createElement('div')` создан новый блок с классом `new-div` и текстом «Мен жаңа элементпін». Метод `document.body.appendChild(newDiv)` добавляет его в конец `body`. Блок отображается только при открытом задании 1; при переходе в другие разделы скрывается свойством `hidden`.
3. Элемент с классом `old-element` найден через `document.querySelector()` и удалён методом `remove()`.
4. Через `document.createElement('p')` создан абзац «Бұл ауыспалы абзац» и добавлен в блок `paragraph-demo`.
5. Нажатие на абзац переключает класс `changed` методом `classList.toggle()`. CSS меняет размер шрифта с 18 до 28 пикселей и цвет текста на розовый. Повторное нажатие возвращает исходное оформление. В светлой теме используется более тёмный оттенок розового.

Абзац также доступен с клавиатуры: его можно выбрать клавишей Tab и активировать Enter или пробелом. Атрибут `aria-pressed` отражает состояние изменения.

Замена текста, создание элементов и удаление старого элемента выполняются при загрузке страницы. Нажатие требуется только для изменения оформления абзаца.

## Задание 2 — управление классами

В `index.html` добавлены демонстрационный блок `class-demo`, кнопка `toggle-class-btn` и отдельный абзац `class-list` для вывода классов.

Обработчик кнопки в `script.js` выполняет `classDemo.classList.toggle('active')`: добавляет класс `active`, если его нет, и удаляет, если он уже существует. При добавлении класса блок получает светло-зелёный фон и тёмный текст. Надпись кнопки меняется в зависимости от следующего действия.

Функция `showClasses()` получает все классы демонстрационного блока через `Array.from(classDemo.classList).join(', ')` и выводит их:

- на страницу, в отдельный тег `p` с ID `class-list`;
- в консоль браузера через `console.log()`.

Список выводится при загрузке страницы и обновляется после каждого нажатия. Изначально он содержит `dom-demo, class-example`, а после включения — `dom-demo, class-example, active`.

## Оформление — styles.css

Добавлены стили зелёной строки «ПРАКТИКА DOM» и округлых кнопок по образцу изображения. Также оформлены демонстрационные блоки, изменяемый абзац, список классов и новый `div`. Для активного элемента задания 2 и изменённого абзаца заданы отдельные правила.

В функцию `switchTab()` добавлена поддержка заданий 1–2 и управление видимостью нового `div`.

## Как посмотреть результат

1. Откройте `index.html` в браузере или через Live Server в VS Code.
2. Нажмите «Тапсырма 1»: проверьте приветствие «Сәлем, әлем!» и новый блок «Мен жаңа элементпін» под основным содержимым. Старого элемента на странице быть не должно.
3. Нажмите абзац «Бұл ауыспалы абзац»: его цвет и размер изменятся. Повторное нажатие вернёт исходный вид.
4. Откройте «Тапсырма 2» и нажмите кнопку управления классом. Оформление блока и список классов должны измениться.
5. Откройте инструменты разработчика клавишей F12, вкладку Console. После нажатий там появляется актуальный список классов.

При внесении изменений выполнена проверка синтаксиса командой `node --check script.js` и проверка изменений командой `git diff --check`. Проверка взаимодействий в браузере тогда не выполнялась; шаги выше предназначены для ручной проверки.

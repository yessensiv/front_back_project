# Справочник: задачи 3 и 4

## Задача 3 — динамическая таблица

### HTML-теги и атрибуты

| Элемент | Где используется | Назначение |
| --- | --- | --- |
| `<section>` | `#view-task3` | Отдельная вкладка для задания. |
| `<label>` | Поля ввода количества строк и столбцов | Подписывает поле ввода; `for` связывает подпись с `id` поля. |
| `<input type="number">` | `#rows-input`, `#cols-input` | Принимает число строк и столбцов. Атрибуты `min="1"`, `max="20"`, `step="1"` и `value` задают диапазон, целые шаги и начальное значение. `aria-describedby="table-error"` связывает поле с текстом ошибки. |
| `<button>` | `#build-table-btn` | По нажатию вызывает построение таблицы. `type="button"` запрещает отправку формы. |
| `<p>` | `#table-error` | Выводит сообщение о неверном размере таблицы. `role="alert"` и `aria-live="assertive"` сразу сообщают текст ошибки программам чтения с экрана. |
| `<p>` | `#colored-counter` | Показывает количество окрашенных ячеек. `aria-live="polite"` сообщает программам чтения с экрана об изменении текста. |
| `<div>` | `#table-container` | Контейнер, в который JavaScript добавляет готовую таблицу. |
| `<table>` | Создаётся в JavaScript | Корневой элемент таблицы. |
| `<tr>` | Создаётся в JavaScript | Одна строка таблицы. |
| `<td>` | Создаётся в JavaScript | Одна ячейка таблицы. |

### JavaScript-команды

| Команда | Назначение |
| --- | --- |
| `document.getElementById()` | Находит элемент по его `id`. |
| `.value` | Получает введённое пользователем значение из `<input>`. |
| `Number()` | Преобразует строку из поля ввода в число для проверки и циклов. |
| `.trim()` | Удаляет пробелы по краям строки; позволяет определить, что поле оставлено пустым. |
| `Number.isInteger()` | Проверяет, что пользователь ввёл целое число. |
| `if / else if / return` | Проверяет данные по порядку: пустое поле, число меньше 1, число больше 20. При ошибке `return` завершает функцию и не создаёт таблицу. |
| `.setAttribute()` | Устанавливает `aria-invalid="true"` на поле с ошибкой. |
| `.removeAttribute()` | Удаляет `aria-invalid`, когда данные снова проверяются. |
| `document.createElement()` | Создаёт элементы `table`, `tr` и `td`. |
| `.className` | Назначает CSS-класс таблице: `dynamic-table`. |
| `for` | Повторяет создание строк и ячеек нужное число раз. |
| `.textContent` | Записывает координаты в ячейку и текст в счётчик. |
| `.onclick` | Назначает действие по нажатию кнопки или ячейки. |
| `.classList.toggle()` | Добавляет или удаляет класс `colored`, меняя цвет ячейки. |
| `document.querySelectorAll()` | Находит все ячейки с классом `colored`. |
| `.length` | Возвращает количество найденных окрашенных ячеек. |
| `.innerHTML = ""` | Очищает контейнер перед созданием новой таблицы. |
| `.appendChild()` | Добавляет строку в таблицу, ячейку в строку и таблицу в контейнер. |

### CSS-классы

| Селектор | Назначение |
| --- | --- |
| `.table-controls` | Оформляет панель полей и кнопки. |
| `.table-container` | Делает контейнер прокручиваемым по горизонтали при необходимости. |
| `.dynamic-table` | Задаёт расстояние между ячейками. |
| `.dynamic-table td` | Задаёт размер, рамку, курсор и анимацию ячеек. |
| `.dynamic-table td.colored` | Красит выбранную ячейку в зелёный цвет. |
| `.colored-counter` | Оформляет счётчик окрашенных ячеек. |
| `.table-error` | Задаёт цвет, отступ и размер текста сообщения об ошибке. |
| `.table-controls input[aria-invalid="true"]` | Подсвечивает рамку поля, которое содержит неверное значение. |

### Проверка размера таблицы

Перед созданием таблицы функция `kesteKuru()` проверяет оба поля.

| Введённые данные | Что увидит пользователь |
| --- | --- |
| Пустое поле | «Кесте өлшемін енгізіңіз.» |
| Отрицательное число, `0` или дробное число | «Жол мен баған саны 1-ден үлкен болуы керек.» |
| Число больше `20` | «Жол мен баған саны 20-дан аспауы керек.» |
| Целые числа от `1` до `20` | Создаётся таблица заданного размера. |

При ошибке поле выделяется красной рамкой, а уже созданная таблица не удаляется. Это помогает пользователю исправить значение, не теряя текущий результат.

## Задача 4 — тёмная тема

### HTML-теги и атрибуты

| Элемент | Где используется | Назначение |
| --- | --- | --- |
| `<section>` | `#view-task4` | Отдельная вкладка для задания. |
| `<p>` | `#theme-status` | Сообщает, какая тема включена сейчас. |
| `<button>` | `#theme-toggle-btn` | Переключает светлую и тёмную темы. |
| `<span>` | `.theme-icon` | Декоративная иконка; `aria-hidden="true"` скрывает её от программ чтения с экрана. |

### JavaScript-команды

| Команда | Назначение |
| --- | --- |
| `document.body` | Обращается к тегу `<body>` всей страницы. |
| `.classList.toggle("light-theme")` | Добавляет класс светлой темы или удаляет его, возвращая тёмную. |
| `.classList.contains("light-theme")` | Проверяет, включена ли светлая тема. |
| `if ... else` | Выбирает текст статуса и подпись кнопки для текущей темы. |
| `.textContent` | Меняет текст статуса и кнопки. |
| `.onclick` | Запускает переключение темы по клику. |

### CSS-классы и селекторы

| Селектор | Назначение |
| --- | --- |
| `:root` | Хранит CSS-переменные тёмной темы по умолчанию. |
| `body.light-theme` | Переопределяет переменные для светлой темы. |
| `body:not(.light-theme)` | Применяет стили, когда активна тёмная тема. |
| `.theme-demo-card` | Оформляет карточку настройки темы. |
| `.theme-demo-card .action-button` | Располагает кнопку переключения в карточке. |

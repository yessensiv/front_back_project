# 1 және 2-тапсырмалар: толық анықтама

Бұл құжат сайттағы DOM практикасының 1 және 2-тапсырмаларын түсіндіреді. Екі тапсырманың интерфейсі қазақ тілінде, ал барлық әрекет пайдаланушы басатын батырмалар арқылы орындалады.

## Қай файлдарда код орналасқан

| Файл | Мазмұны |
| --- | --- |
| `index.html` | Вкладкалар, мәтіндер, батырмалар және тапсырма блоктары. |
| `script.js` | Батырманы басқаннан кейін DOM-ды өзгертетін JavaScript коды. |
| `styles.css` | Элементтердің түсі, өлшемі, фон, белсенді және қараңғы тақырып стильдері. |

---

# 1-тапсырма — DOM элементтерімен жұмыс

## Мақсаты

1-тапсырма төрт негізгі DOM әрекетін көрсетеді:

1. ID арқылы мәтінді өзгерту;
2. Абзацтың стилін өзгерту;
3. Жаңа `div` элементін жасау және қосу;
4. Ескі элементті жою.

Маңыздысы: бұл өзгерістердің ешқайсысы сайт жүктелгенде өздігінен орындалмайды. Әр әрекет өз батырмасы басылғанда ғана іске қосылады.

## HTML: батырмалар мен элементтер

### 1. Мәтінді өзгерту

```html
<p id="greeting">Бастапқы мәтін</p>
<button id="change-greeting-btn" class="action-button" type="button">
  Мәтінді өзгерту
</button>
```

- `id="greeting"` — өзгертілетін мәтінді табуға арналған бірегей атау;
- `id="change-greeting-btn"` — JavaScript батырманы осы ID арқылы табады;
- `class="action-button"` — барлық әрекет батырмаларына бірдей CSS стилін береді;
- `type="button"` — батырма форма жібермейтінін көрсетеді.

### 2. Абзац стилін өзгерту

```html
<p id="changeable-paragraph" class="changeable-paragraph">
  Бұл ауыспалы абзац
</p>
<button id="change-text-btn" class="action-button" type="button">
  Стильді өзгерту
</button>
```

Абзац бастапқыда `changeable-paragraph` класымен көрсетіледі. Батырма басылғанда JavaScript оған `changed` класын қосады не қайта өшіреді.

### 3. Жаңа элемент қосу

```html
<button id="add-div-btn" class="action-button" type="button">
  Жаңа div қосу
</button>
<div id="new-div-place"></div>
```

`new-div-place` — JavaScript жасаған жаңа `div` шығатын бос контейнер.

### 4. Ескі элементті жою

```html
<div class="old-element">Бұл ескі элемент жойылады.</div>
<button id="delete-old-btn" class="action-button" type="button">
  Ескі элементті жою
</button>
```

`old-element` класы жойылатын блокты табу үшін қолданылады.

## JavaScript: мәтінді өзгерту

```javascript
const greeting = document.getElementById("greeting");
const greetingBatyrmasy = document.getElementById("change-greeting-btn");

greetingBatyrmasy.onclick = function () {
  greeting.textContent = "Сәлем, әлем!";
};
```

Бұл кодтың жұмыс реті:

1. `getElementById("greeting")` HTML-дегі мәтін абзацын табады;
2. `getElementById("change-greeting-btn")` батырманы табады;
3. `onclick` батырма басылған сәттегі әрекетті жазады;
4. `textContent` абзацтың ішіндегі мәтінді ауыстырады.

`textContent` HTML тегін емес, қауіпсіз жай мәтінді жазады. Сондықтан бұл әдіс мәтінді өзгертуге ыңғайлы.

## JavaScript: класс арқылы стильді ауыстыру

```javascript
const changeableParagraph = document.getElementById("changeable-paragraph");

function changeParagraphStyle() {
  changeableParagraph.classList.toggle("changed");
}

ozgertuBatyrmasy.onclick = changeParagraphStyle;
```

`classList.toggle("changed")` екі әрекет жасайды:

- егер `changed` класы жоқ болса, оны қосады;
- егер класс бар болса, оны өшіреді.

CSS-тегі осы ереже класс қосылғандағы көріністі береді:

```css
.changeable-paragraph.changed {
  color: #e879b0;
  font-size: 28px;
}
```

Яғни JavaScript түс пен өлшемді тікелей орнатпайды: ол тек класс қосады. Ал CSS сол класқа сай стильді қолданады.

## JavaScript: жаңа `div` қосу

```javascript
divKosuBatyrmasy.onclick = function () {
  const janaDiv = document.createElement("div");
  janaDiv.className = "new-div";
  janaDiv.textContent = "Мен жаңа элементпін";
  document.getElementById("new-div-place").appendChild(janaDiv);
  divKosuBatyrmasy.disabled = true;
  divKosuBatyrmasy.textContent = "Жаңа div қосылды";
};
```

Түсіндірме:

- `document.createElement("div")` — браузер жадында жаңа `div` жасайды;
- `className = "new-div"` — жаңа блокқа CSS класын береді;
- `textContent` — блок ішіндегі жазуды орнатады;
- `appendChild(janaDiv)` — блокты `new-div-place` контейнерінің ішіне қосады, сондықтан ол экранда пайда болады;
- `disabled = true` — батырманы өшіреді. Бірнеше рет басқанда бірнеше бірдей `div` қосылмайды;
- соңғы `textContent` батырма атауын «Жаңа div қосылды» деп өзгертеді.

## JavaScript: элементті жою

```javascript
zhouBatyrmasy.onclick = function () {
  document.querySelector(".old-element").remove();
  zhouBatyrmasy.disabled = true;
  zhouBatyrmasy.textContent = "Элемент жойылды";
};
```

`document.querySelector(".old-element")` `.old-element` класы бар бірінші элементті табады. Нүкте (`.`) бұл класс атауы екенін білдіреді. `remove()` сол элементті DOM-нан толық жояды.

Жойғаннан кейін батырма өшіріледі, өйткені өшірілген элементті екінші рет жоюға болмайды.

## 1-тапсырмадағы CSS кластары

| Класс | Не істейді |
| --- | --- |
| `.dom-demo` | Әр мысалды жеке карточка ретінде көрсетеді. |
| `.action-button` | Батырманың түсін, шегін, ішкі бос орнын және курсорын баптайды. |
| `.action-button:disabled` | Өшірілген батырманы солғындау көрсетеді және курсорын өзгертеді. |
| `.changeable-paragraph` | Ауыспалы абзацтың бастапқы стилі. |
| `.changed` | Абзацтың өзгерген стилі: үлкенірек және басқа түсті болады. |
| `.new-div` | JavaScript жасайтын жаңа блоктың стилі. |
| `.old-element` | Жоюға арналған бастапқы элемент. |

# 2-тапсырма — Элемент кластарын басқару

## Мақсаты

2-тапсырма `classList` арқылы бір элементке `active` класын қосуды және алып тастауды көрсетеді. Сонымен бірге элементте қандай кластар бар екені экранда және браузер консолінде жазылады.

## HTML

```html
<div id="class-demo" class="dom-demo class-example">
  Класы өзгеретін элемент
</div>

<button id="toggle-class-btn" class="action-button" type="button">
  active класын қосу
</button>

<p id="class-list" class="class-list"></p>
```

Бастапқыда блокта екі класс бар: `dom-demo` және `class-example`. Батырманы басқанда үшінші — `active` класы қосылады.

## JavaScript

```javascript
const classDemo = document.getElementById("class-demo");
const toggleClassButton = document.getElementById("toggle-class-btn");

toggleClassButton.addEventListener("click", () => {
  const active = classDemo.classList.toggle("active");
  toggleClassButton.textContent = active
    ? "active класын жою"
    : "active класын қосу";
  showClasses();
});
```

### `addEventListener("click", ...)`

Бұл әдіс батырмаға тыңдаушы қосады. Бірінші аргумент — оқиға атауы (`"click"`), ал екінші аргумент — сол оқиға болғанда орындалатын функция.

### `classList.toggle("active")`

Бұл әдіс `active` класын ауыстырады және оның қорытынды күйін қайтарады:

- класс қосылса, нәтиже `true`;
- класс өшірілсе, нәтиже `false`.

Сондықтан `active` айнымалысы батырма мәтінін дұрыс таңдауға көмектеседі.

### Тернарлық оператор `? :`

```javascript
active ? "active класын жою" : "active класын қосу"
```

Бұл қысқа `if / else` жазылуы:

- `active` шын болса, бірінші мәтін алынады;
- жалған болса, екінші мәтін алынады.

## Барлық кластарды шығару

```javascript
function showClasses() {
  const classes = Array.from(classDemo.classList).join(", ");
  document.getElementById("class-list").textContent = "Кластар тізімі: " + classes;
  console.log("Кластар тізімі:", classes);
}
```

Мұнда:

- `classDemo.classList` — элемент класстарының тізімі;
- `Array.from(...)` — сол тізімді кәдімгі массивке айналдырады;
- `join(", ")` — класстарды үтір арқылы бір мәтінге біріктіреді;
- `console.log()` — сол ақпаратты браузердің Developer Tools → Console бөлігіне шығарады.

## 2-тапсырмадағы CSS

```css
.class-example.active {
  background: #d8e9d6;
  border-color: #829d87;
  color: #304d37;
}
```

Бұл селектор `class-example` және `active` деген екі классы да бар элементті таңдайды. `active` қосылғанда фон, жиек және мәтін түсі өзгереді. Класс жойылса, элемент бастапқы `dom-demo` стиліне оралады.

# Қорғауға арналған қысқа мәтін

> 1-тапсырмада DOM элементтерімен батырмалар арқылы жұмыс істеймін. Бір батырма ID арқылы мәтінді өзгертеді, екіншісі класс қосып абзац стилін ауыстырады, үшіншісі `createElement` және `appendChild` арқылы жаңа `div` жасайды, ал төртіншісі `querySelector` және `remove` арқылы ескі элементті жояды.

> 2-тапсырмада `classList.toggle('active')` әдісін қолдандым. Батырма басылған сайын `active` класы қосылады не жойылады. CSS сол класқа байланысты блоктың стилін өзгертеді, ал экранда элементтің барлық кластары көрсетіледі.
